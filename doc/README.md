## Adding a document

| Rule | Detail |
| --- | --- |
| One topic per file | Split instead of growing a catch-all page |
| File name | UpperCamelCase, e.g. `EdgeStrategies.md`. `README.md` keeps its usual name |
| Index | Add a row to the table above |
| Diagrams | Prefer tables and ASCII diagrams in the Markdown itself. When one must be an image, put it in `doc/images/` |
